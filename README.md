# DSA0115-192425124

This repository contains the implementation and supporting notes for the assigned Data Structures and Algorithms coursework.

## Repository structure

- `assignments/CO1/Implementation/README.md` — assignment overview, compile/run instructions, and behavior notes
- `assignments/CO1/Implementation/metro_fare_system.cpp` — C++ implementation of the metro smart-card fare system
- `assignments/CO1/Implementation/test_cases.txt` — sample test inputs and expected results

## Project focus

The current assignment is a metro smart-card fare system that:

- calculates fare based on origin/destination zone
- applies peak-time surcharges
- supports student and senior concessions
- validates card balance before payment
- includes built-in automated tests for core behavior
