# Task B3 – Performance Benchmarks

Compile the virtual/switch benchmark and run it:

```bash
g++ -std=c++17 -O2 -Wall -Wextra main.cpp -o main
./main
```

Compile and run the exception benchmark:

```bash
g++ -std=c++17 -O2 -Wall -Wextra benchmark.cpp -o benchmark
./benchmark
```

Run both several times for assignment evidence. Timing values must come from
the actual terminal output. Do not copy values from another computer.
